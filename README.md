# Jasmine Speed Booster

**Jasmine Speed Booster**는 아스트랄 파티(*Astral Party*)의 PvE 대전을 더 빠르게 진행할 수 있도록 돕는 **Windows용 비공식 배속 프로그램**입니다. 기본적으로 자스민을 플레이할 때 작동하며, 설정에서 다른 캐릭터도 사용할 수 있습니다.

## 다운로드

**최신 버전: v1.0.0** — [GitHub Releases](https://github.com/Shushu1121/JasmineSpeedBooster-Releases/releases/latest)

`JasmineSpeedBooster_v1.0.0_Windows.zip`을 다운로드하세요.

## 주요 기능

- **이동 시 배속:** 자신의 턴에 발판 사이를 이동할 때 가속합니다. 전투·결과 화면은 별도로 설정할 수 있습니다.
- **상시 배속:** 자신과 다른 플레이어의 턴, 선택 화면, 전투, 결과 화면 등 게임 진행 전반을 가속합니다.
- **8단계 배율:** x1.5 / x2 / x2.5 / x3 / x3.5 / x4 / x4.5 / x5
- **화면 표시:** 우측 상단 배속 상태, 우측 하단 가속 표시, 집중선, 화면 밖의 도달 가능한 질주 발판 방향
- **편의 기능:** '빨리빨리' 버프 표시, 사용자 지정 단축키, UI 투명도 조절, 캐릭터 제한 해제
- **설정:** 한국어·영어·일본어·중국어 지원, 자동 저장

## 설치 및 실행

1. [Releases](https://github.com/Shushu1121/JasmineSpeedBooster-Releases/releases/latest)에서 ZIP을 다운로드해 **압축을 완전히 풉니다.**
2. 게임을 종료한 상태에서 `dist/JasmineSpeedBooster.exe`를 실행합니다.
3. 게임 설치 경로를 확인하면 필요한 구성요소가 설치됩니다.
4. 이후 **PvE 대전에 참가하면 자동으로 실행**되며, 대전에서 나가면 자동 종료됩니다.

기존 모드 파일은 보존하도록 설계되어 있습니다. 첫 설치 후 게임 실행에 시간이 더 걸릴 수 있습니다.

## 기본 단축키

| 키 | 기능 |
|---|---|
| `` ` `` (백틱) | 배속 ON/OFF |
| `1` | 이동 시 ↔ 상시 모드 전환 |
| `2` | x2 ↔ x4 빠른 배율 전환 |
| `3` | 우측 상단 배속 정보 표시/숨기기 |
| 왼쪽 `Shift` | 누르는 동안 즉시 배속 |

모든 단축키는 설정 창의 **단축키** 탭에서 변경할 수 있습니다. 숫자 단축키는 키보드 윗줄 숫자 키입니다. 다른 배율에서 `2`를 누르면 x2로 전환됩니다. 왼쪽 Shift는 배속을 꺼 둔 상태에서도 작동합니다.

## 설정 및 제거

게임 밖에서는 `JasmineSpeedBooster.exe`를 다시 실행하고, 게임 중에는 **Windows 트레이 아이콘**을 클릭해 설정 창을 엽니다. 설정은 즉시 적용되고 자동 저장됩니다.

기본 설정은 **배속 ON · 이동 시 · x2**입니다. 다른 캐릭터에도 적용하려면 **캐릭터 제한 해제**를 켜세요.

제거할 때는 게임과 부스터를 종료한 뒤 `dist/JasmineSpeedBooster_Uninstall.exe`를 실행합니다. 제거 후 압축을 푼 폴더를 삭제하면 됩니다.

## 지원 환경

- **Windows 10/11**, 아스트랄 파티 **Steam Global/INT**, **PvE 대전**
- **권장:** 주 모니터 전체화면, 1920×1080(16:9)
- 창모드는 지원하지 않으며, 다른 해상도나 화면 배율에서는 일부 표시 위치가 어긋날 수 있습니다.
